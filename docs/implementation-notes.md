# Implementation notes

This repository is an original educational reimplementation focused on **CameraX Photo Video Analysis Lab**. It intentionally keeps the UI small so the platform/API behavior is easy to inspect. Hardware- or service-dependent paths fail gracefully where possible.

Build baseline: Android Gradle Plugin 9.3.0, Gradle 9.5.0, Java 17, compile SDK Android 17 / API 37.1, target SDK 37.
